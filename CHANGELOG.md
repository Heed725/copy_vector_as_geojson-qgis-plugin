# Changelog

All notable changes to **Copy Vector as GeoJSON** are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-09-01

### Added

- QGIS vector-layer context-menu integration.
- **Copy as GeoJSON** command.
- **Copy BBOX** command.
- Automatic selected-feature handling.
- Complete-layer fallback when nothing is selected.
- EPSG:4326 coordinate transformation.
- GeoJSON geometry and attribute export.
- Six-decimal coordinate precision.
- Pretty-formatted clipboard output.
- GeoJSON-style BBOX arrays.
- Processing Toolbox provider and configurable export algorithm.
- QGIS 3.22+ compatibility metadata.
- Installation and usage documentation.
- QGIS branding and project-status badges.
